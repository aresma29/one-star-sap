A one-star review written by a houseplant. It is neglected, it is
parched, and it has noticed that the plastic plant gets the apologies
while it gets nothing. Short, dry, and still standing in its pot,
waiting for a watering can that never comes.

> One star. My human waters me when he remembers, which is never, then apologizes to the plastic plant. I am still here. I am still thirsty.

`main.py` prints `entry.txt` byte for byte — run `python3 main.py` to see the review.
