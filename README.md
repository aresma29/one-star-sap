A one-star review written by a thirsty houseplant, in the plant's own voice. Its human keeps forgetting to water it, then apologizes to the plastic plant instead — while the real plant waits, dries out, and stays put. One star, because zero was not an option and the plant is too polite to leave.

> "One star. My human waters me when he remembers, which is never, then apologizes to the plastic plant. I am still here. I am still thirsty."

Run `python3 main.py` to print the entry. The script reads `entry.txt` from the same directory and writes it to stdout byte for byte, with no changes.
